# MoonHEALPix 架构与实现边界

本文描述 0.2.0 本地集成源码，以 [公开接口](../pkg.generated.mbti) 为准。生产代码位于同一 MoonBit 包内；Python 独立参考仅用于开发测试。工具链和运行命令见 [README](../README.md)，本文不推断远端持续集成或发布状态。

## 模块与数据流

| 文件 | 职责 |
| --- | --- |
| `model.mbt`、`angles.mbt` | 网格、错误、有限值验证、经纬度、单位向量与角距离。 |
| `faces.mbt`、`nested.mbt`、`ring.mbt`、`ordering.mbt` | 十二基面投影、Morton 位交错、纬圈编号和顺序转换。 |
| `geometry.mbt`、`hierarchy.mbt` | 连续面坐标、曲边采样、父子单元与 NUNIQ。 |
| `neighbours.mbt`、`interpolation.mbt` | 标准八邻域、四点插值、极区和缺失值处理。 |
| `ranges.mbt`、`coverage.mbt` | 半开区间集合、代数、层级展开与压缩。 |
| `query.mbt`、`regions.mbt` | 沿纬圈的圆与经纬框中心选择。 |
| `polygon.mbt`、`cell_caps.mbt`、`spatial_query.mbt` | 凸球面多边形、完整像素包围圆、NESTED 层级中心查询和保守覆盖。 |
| `moc.mbt` | 受限 ICRS 空间 MOC、元数据、集合运算、ASCII / JSON 解析与输出。 |
| `catalog.mbt`、`catalog_tree.mbt` | 稀疏源桶、真实源包围圆树、锥形查询及计数图。 |
| `maps.mbt`、`map_order.mbt`、`binning.mbt`、`resample.mbt` | 稠密可缺失地图、编号重排、掩膜、统计和层级重采样。 |

方向经 `Grid` 转为编号后，可建立稀疏目录或稠密地图。区域查询产生带网格及顺序的 `PixelSet`，地图掩膜要求两者匹配。NESTED 集合可压缩为 `Cell`，也可显式构造空间 `Moc`；MOC 存储的是离散集合，保留输入集合原有的近似边界。

## 基础不变量与所有权

`nside` 是 `1..8192` 内的二次幂，order 为 `0..13`，像素数为 `12*nside²`。当前像素编号和 NUNIQ 在有符号 32 位范围内；最大网格的 805306368 个像素并不适合默认分配为稠密数组。`resolution()` 是面积平方根，不是保守包围半径。

RING 按纬圈排列，NESTED 按基面四叉层级排列。`Cell`、`FaceXY`、目录桶固定使用 NESTED；编号转换必须进行实际置换，不能只更改标签。`PixelRange` 为半开区间，`PixelSet` 规范化后有序、不重叠且不相接。

`LonLat` 只保存方向，不自动变换参考系或历元；MOC 的 ICRS 前提由调用者保证。向量构造拒绝零向量和非有限值，缩放后归一化；角距离使用叉积长度与点积的 `atan2`。所有几何采用 `Double`，边界判定受浮点容差影响。

构造器复制源、值或区间输入，公开数组访问器返回副本。地图更新、重排和掩膜产生新图。`None` 表示缺失，有限的 `Some` 才是有效值；非有限统计结果抛错，不转为看似成功的零值。

## 邻域与插值

八邻域使用基面内的相邻坐标和跨面映射，固定顺序为 SW、W、NW、N、NE、E、SE、S。固定八槽中的不存在邻居为 `-1`。RING 输入转换到相应内部表示，输出再转回要求的顺序。

插值选择相邻纬圈，各取经度两侧像素，再组合纬向和经向权重。极区使用极端纬圈四像素平均参与插值，精确极点权重各为四分之一。高分辨率极区需避免从接近一的正弦值反求纬度造成精度损失；实现单独处理极区纬圈角度。独立参考涵盖两种顺序和高 nside，非仅自往返。

`bilinear_interpolation_weights` 返回四个编号及权重，前后各一对纬圈像素；槽位不是方位顺序。`interpolate_bilinear` 严格检查四个槽位，任何缺失都返回 `None`，包括零权重槽位；不补值也不重归一化。浮点边界上的零权重角点选择可能因实现不同而变化，不能将缺失传播仅按非零系数解释。

## 中心查询与连续区域覆盖

多边形限定为**包含在某个开半球内、以短大圆弧为边的凸球面多边形**，支持两种绕序。构造器检查顶点、边及凸半空间关系，不支持凹形、孔洞或长弧边。顶点数至少三，最多 4096，并受调用者 `max_vertices` 预算限制；验证有二次复杂度。包含判定采用有向大圆半空间及实现中的边界容差。

旧 `query_disc` / `query_box` 按纬圈生成 RING 中心集合。新 `search_disc` / `search_polygon` 从十二个 NESTED 根单元递归：包围圆证明不相交时剪枝，证明完全在内时加入后代区间，其余细分，在目标层级用中心谓词决定命中。`query_polygon` 直接返回多边形中心查询的 NESTED 集合。中心选择不能代替实际曲边像素覆盖。

`Cell::bounding_radius` 包围整个连续曲边像素，使用面投影极值与极区/赤道区分界交点；它不是用有限边界采样估出的半径。`Cell::boundary` 则仅提供可视化采样，不承担包围或精确相交证明。

`cover_disc` / `cover_polygon` 使用保守包围判据和可选的更深细分，返回调用网格上的 NESTED `RegionCover`：

- `pixels()` 为可能相交的保守候选，允许误报。
- `interior()` 保证整像素在区域内，但不保证识别全部实际全内像素。
- `boundary()` 为候选减全内集，表示未决，不是精确交界集合。
- `refine_levels` 为额外层数，范围 `0..13-grid.level()`；`refinement_level()` 是绝对停止层级。

这些操作**不是解析精确相交**。细分能排除部分误报，输出仍是目标分辨率的保守集合。与之不同，`cover_cells` 是离散层级单元的集合展开。

`max_pixels` 约束结果像素数量；`max_work` 和 `visited()` 对层级单元访问计数，包含细分工作，目标单元进入细分时可能再次计数。压缩区间可表示大量像素，访问次数不等于结果大小，更不等于分配次数或总指令数。

## 目录树与预算兼容性

目录复制输入，保留原始下标，按 NESTED 编号排序为占用桶。每桶包围圆覆盖桶内实际源；按占用桶构造平衡二叉包围圆树，叶节点最多包含四桶。查询先检查节点，再检查桶，最后逐源验证闭圆条件 `distance <= radius`。因此剪枝不依赖近似像素分辨率来代替源位置。

`search_cone` 返回命中与 `visited_nodes()`、`tested_sources()`；`query_cone` 调用同一路径并仅返回命中。**两者的 `max_work` 均为访问节点数加逐项源检查数**；这改变了 0.1.0 的预算含义，虽然 `query_cone` 签名保持不变。桶检查、内存分配及结果排序不单独计入此预算。

结果按角距离升序，再按原始输入下标排序。构造包含排序，查询最坏仍可能访问整棵树和全部源，另有命中数 H 的 `O(H log H)` 排序；不保证任意目录和半径下对数时间。计数适合解释一次查询的剪枝工作，不构成跨库性能比较。

`examples/spatial` 的固定输入在本地 js 下得到：多边形候选 65、全内 13、未决 52、访问 902；nside8192 的零半径中心查询访问 352；12000 源目录半径 0.02 查询访问 249 个节点、检查 1 个源并命中 1，结果逐源对照一致。这是操作计数记录，不是计时结果。

## 空间 MOC

只实现 MOC 2.0 的 **ICRS 空间 order 0..13**，提供第 4.3.2 节规范 ASCII 及附录 F 信息性 JSON。没有 FITS、时间、频率或时空 MOC，也不提供坐标参考系转换。

内部以 order13 的规范 NESTED 区间保存覆盖，独立保存声明最大层级。兄弟单元压缩及空集仍保留层级元数据；`equals` 只比较覆盖。单元与 NUNIQ 构造器规范化重叠，文本解析器额外拒绝重复或重叠；`from_pixel_set` 要求 NESTED，较细集合必须能在声明层级无损表达。

ASCII 按层级与编号递增，编号范围两端包含，分隔符仅普通空格、回车和换行，允许可选 `s` 前缀；例如 `13/` 可表达带层级元数据的空集。JSON 接收层级对象或仅含 `s` 的包装对象，输出无包装对象和逐项编号数组。拒绝重复键、非整数编号、额外维度、尾随内容及非法重叠。解析按有限结构处理，不构建任意深度的通用 JSON 树。

`MocLimits` 默认且最大允许 `100000` 个候选区间、`100000` 个物化单元、`4194304` 个文本 UTF-16 代码单元；零合法。区间限制检查规范化前的候选，不能靠大量重复输入绕过。非法文本报 `InvalidData`，不支持的层级报 `InvalidOrder`，预算超限报 `ResourceLimit`，不截断后返回成功。

## 地图、统计与资源

`ScalarMap` 是 `Array[Double?]` 稠密结构；`sample` 读取所在像素，插值需显式调用。重采样按 NESTED 父子层级计算并保留地图顺序：`Mean` 向下平均有效子像素、向上复制；`Sum` 向下累加、向上均分。缺失不会自动补偿。

分箱同时产生计数、权重、加权和、均值和总体方差。空桶计数及权重为零，无有效观测时其余图为缺失。像素均值的普通平均不等价于源级加权平均，跨分辨率观测汇总应保留权重和加权和。

地图副本及工作数组可能同时存活；`values`、`with_value`、`reorder`、`masked`、`coalesce` 没有各自的输出预算。部分集合操作也无统一内存上限。所有显式预算都是算法计数约束，不是字节或时间沙箱，详见 [安全说明](../SECURITY.md)。

## 验证分层

索引、邻域及插值使用固定版本 astropy-healpix 独立资料；多边形使用 spherical-geometry，圆与面坐标使用 Astropy / astropy-healpix；空间 MOC 使用 mocpy 检查实际输出的覆盖与最大层级。暴力遍历、数学不变量、错误回归与上述独立参考互补。MOC 的独立验证不能推广为几何覆盖算法完全等价，有限曲面采样不能替代解析证明。生成器与许可见 [第三方说明](../THIRD_PARTY.md)。
